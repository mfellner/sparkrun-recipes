# Drama 3 GB10 Single-Node Service Implementation Plan

**Goal:** Deliver a genuinely exercised, single-GX10 Drama 3 FP8/BF16 TTS service, a reusable recipe in mfellner/sparkrun-recipes, immutable runtime/model pins, automated tests, preserved live evidence, independent approval of the exact staged tree, and a verified push to main.

**Architecture:** One ARM64 CUDA server on dgx02, managed by SparkRun when feasible. Keep Fish's block-FP8 experts and BF16 dense weights; qualify native Fish first. A narrowly scoped adapter may provide standardized health/models/API endpoints and browser UI if the native server lacks these. Use a purpose-built public ARM64 image and persistent model/compiler/reference/output caches. Do not shard or quantize further before stock correctness is established. Keep dgx01 Hermes gateway and sparkDash untouched.

**Tech stack:** Python 3.12; reviewed pinned Fish Speech source; compatible ARM64 CUDA 13 / PyTorch / Triton; Docker/NVIDIA runtime; SparkRun 0.3.6; HTTP TTS/WAV streaming; pytest; ffprobe; available local ASR for intelligibility checks; GitHub CLI and GHCR.
