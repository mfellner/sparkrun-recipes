# Qwen3.8 Flash Next NVFP4 upstream PLE mod

This SparkRun mod vendors the PLE module generated by MiaAI-Lab's launcher at upstream commit `169fbad266f2791335a3102f0d3d625e7c295563` for the pinned `vllm/vllm-openai:qwen38-flash-next` arm64 image. The vendored module is derived from vLLM source and remains subject to the Apache License 2.0; see https://github.com/vllm-project/vllm/blob/main/LICENSE.

`run.sh` verifies the vendored bundle and the image's unmodified PLE module before installing the upstream resolver shim. The shim is activated only by `PLE_QUANT_OVERRIDE=fp8`, matching upstream. `serve_wrapper.sh` preserves SparkRun's native distributed arguments and adds a rank-0 fail-closed readiness plus exact semantic-completion gate because cold startup exceeds SparkRun's generic post-hook wait.

The vendored `ple_layer_patched.py` retains its upstream Apache-2.0 SPDX header. The wrapper and gate are MIT-licensed with this registry.
